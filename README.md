# agrinho 
O objetivo desse site é apresentar o conceito de "Agro do Futuro" (AgroTech), mostrando como a tecnologia está transformando a agricultura.


2. O Agro do Futuro

Explica o que é a agricultura moderna:

* Inteligência Artificial
* Robótica
* Sensores inteligentes
* Monitoramento por celular
* Máquinas autônomas

A ideia é mostrar que a agricultura atual usa tecnologia para produzir melhor.


3. Tecnologias Revolucionárias

Mostra exemplos de tecnologias usadas no campo:

* 🚁 Drones agrícolas
* 🧠 Inteligência Artificial
* 🔬 Sensores inteligentes
* 🤖 Robôs de colheita
* 🛰️ Satélites
* 🚜 Tratores autônomos

Cada card explica para que serve cada tecnologia.

4. Linha do Tempo

Mostra a evolução da agricultura:

| Período | Evolução |
| --------- | ----------------------- |
|      1900 | Agricultura tradicional |
| 1900–1960 | Mecanização |
| 1960–2000 | Agricultura de precisão |
| 2000–2020 | Agricultura 4.0 |
| 2020+ | Agro do futuro |

Serve para mostrar como o campo evoluiu ao longo dos anos.
 5. Quiz

Tem um questionário com 10 perguntas sobre o conteúdo apresentado.

Quando o usuário responde:

* calcula a pontuação;
* mostra acertos e erros;
* exibe um gabarito detalhado.

Isso deixa a apresentação mais interativa.


 6. Conclusão

Resume a ideia principal:

* A tecnologia já faz parte do agronegócio.
* O objetivo é produzir mais alimentos.
* Reduzir desperdícios.
* Diminuir impactos ambientais.
* Tornar a agricultura mais sustentável.
